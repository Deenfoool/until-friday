# До пятницы — планы

Игра уже содержит полный цикл из пяти рабочих дней. Этот список отделяет готовые возможности от будущей работы; подробное описание истории находится в [README.md](README.md).

## Готово

- [x] Меню, пролог, профиль сотрудника и продолжение сохранения.
- [x] Пять дней, условные события и последствия решений.
- [x] Рабочие мини-задачи, документы, почта и Терминал.
- [x] МИН с коллегами, сюжетными ответами и необязательным P2P.
- [x] Пятничная встреча, десять основных концовок и итоговый экран.
- [x] Единый рантайм с атомарным сохранением и откатом при ошибках.
- [x] Сброс прохождения с подтверждением и сохранением настроек.
- [x] Событийное обновление интерфейса без глобального наблюдения DOM.
- [x] Общий обработчик перетаскивания окон.
- [x] Автоматические проверки маршрутов, сохранений и регрессий производительности.

## Ближайшая работа

- [ ] Пройти всю неделю вручную на настольном браузере и телефоне.
- [ ] Проверить реальные P2P-соединения и звонки между двумя устройствами.
- [ ] Измерить производительность длительной сессии на слабом устройстве.
- [ ] Проверить все приложения клавиатурой и улучшить доступность найденных проблем.
- [ ] Собрать отзывы игроков о понятности задач и балансе времени.

## Возможное развитие

- [ ] Добавлять новые разговоры и реакции только с проверкой доступности веток.
- [ ] Расширять рабочие задания, сохраняя возможность честного прохождения.
- [ ] Сокращать дублирование стилей и модулей по мере изменений интерфейса.

## Принципы

Не показывать шкалы морали и подозрения. Проявлять последствия через людей и документы. Оставлять уликам несколько трактовок. Делать честную работу полноценным маршрутом. Определять финал решениями всей недели.
