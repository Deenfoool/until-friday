# До пятницы

Браузерная психологическая игра, которая выглядит как обычный рабочий компьютер офисного сотрудника.

Главный герой случайно слышит, что в пятницу кого-то собираются уволить, но не знает, идёт ли речь о нём. За пять рабочих дней игрок сам решает, выполнять работу, искать правду, собирать компромат или нарушать правила компании.

## Текущая версия

Реализован вертикальный срез понедельника:

- вступительная сцена;
- рабочий стол и оконный интерфейс;
- Проводник с файлами и закрытыми папками;
- корпоративная Почта;
- мессенджер «Связь»;
- три рабочие задачи;
- вымышленный Терминал;
- скрытые последствия действий;
- локальное сохранение;
- итог первого рабочего дня.

## Запуск

Сборка не требуется.

1. Скачайте репозиторий.
2. Откройте `index.html` в браузере.

Для локального сервера можно использовать:

```bash
python -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Управление

- двойной щелчок по значку открывает приложение;
- окна можно перетаскивать и сворачивать;
- кнопка часов открывает завершение рабочего дня;
- прогресс сохраняется в `localStorage`;
- команды Терминала перечислены командой `help`.

## Структура

```text
index.html          каркас игры
styles.css          интерфейс операционной системы
src/data.js         сюжетный контент понедельника
src/app.js          игровая логика и приложения
assets/             будущие изображения и звуки
ROADMAP.md          полный план разработки
```

## Принципы проекта

- никаких видимых шкал морали, подозрения или репутации;
- любая улика допускает несколько трактовок;
- честная работа должна быть полноценной частью геймплея;
- нарушения и команды Терминала полностью вымышлены;
- интерфейс намеренно простой и похож на реальный офисный компьютер.
