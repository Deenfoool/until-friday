# До пятницы

Браузерная психологическая игра, которая выглядит как обычный рабочий компьютер офисного сотрудника.

Главный герой случайно слышит, что в пятницу кого-то собираются уволить, но не знает, идёт ли речь о нём. За пять рабочих дней игрок сам решает, выполнять работу, искать правду, собирать компромат или нарушать правила компании.

## Текущая версия

Реализован единый прототип всей рабочей недели:

- вступительная сцена;
- рабочий стол и оконный интерфейс;
- пять игровых дней;
- четыре скрытых варианта правды;
- Проводник, Почта, «Связь», Задачи, Терминал, Журнал и Корзина;
- скрытые последствия действий;
- ограничения на взаимоисключающие решения;
- локальное сохранение и миграция старых сохранений;
- десять базовых концовок;
- автоматические тесты движка;
- программный индикатор загрузки;
- интеграция полного набора визуальных ассетов.

Сгенерированные спрайт-листы не требуют ручной нарезки. Иконки файлов, папок, статусов, уведомлений и вложений извлекаются через canvas во время работы игры.

## Запуск

Сборка не требуется.

1. Скачайте репозиторий.
2. Запустите локальный статический сервер.

```bash
python -m http.server 8080
```

После этого откройте:

```text
http://localhost:8080
```

Прямое открытие `index.html` может работать, но локальный сервер предпочтительнее из-за загрузки изображений и canvas.

## Управление

- двойной щелчок по значку открывает приложение;
- окна можно перетаскивать и сворачивать;
- кнопка часов открывает завершение рабочего дня;
- прогресс сохраняется в `localStorage`;
- команды Терминала перечислены командой `help`;
- сюжетные фотографии и сканы открываются двойным щелчком в Проводнике.

## Проверки

```bash
node tests/engine.test.js
node tests/story-validation.test.js
node tests/rules-extension.test.js
node tests/ui-contract.test.js
```

Эти проверки также запускаются через GitHub Actions.

## Принципы проекта

- никаких видимых шкал морали, подозрения или репутации;
- любая улика допускает несколько трактовок;
- честная работа должна быть полноценной частью геймплея;
- нарушения и команды Терминала полностью вымышлены;
- интерфейс намеренно простой и похож на реальный офисный компьютер;
- финал зависит от всей недели, а не только от последнего выбора.

Подробное текущее состояние и следующий этап: [`DEVELOPMENT_STATUS.md`](DEVELOPMENT_STATUS.md).
