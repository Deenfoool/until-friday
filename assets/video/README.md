# Ассеты «ВидеоЛенты»

Интерфейс уже ожидает следующие файлы. Пока их нет, используются автоматические заглушки.

## Обложки роликов

- Папка: `assets/video/thumbs/`
- Формат имени: `video-thumb-001.webp` ... `video-thumb-080.webp`
- Рекомендуемый размер: **1280×720 px**
- Соотношение сторон: **16:9**
- Допустимые форматы после переименования ссылок: WebP, PNG, JPG
- Важный текст и лица лучше держать не ближе 60 px к краям

## Аватары каналов

- Папка: `assets/video/channels/`
- Формат имени: `channel-avatar-001.webp` ... `channel-avatar-016.webp`
- Размер: **800×800 px**
- Соотношение сторон: **1:1**
- Аватар отображается круглым, поэтому важные детали должны находиться в центральных 70% изображения

## Баннеры каналов

- Папка: `assets/video/channels/`
- Формат имени: `channel-banner-001.webp` ... `channel-banner-016.webp`
- Размер: **2048×1152 px**
- Центральная безопасная зона: **1235×338 px**
