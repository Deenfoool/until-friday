# Ассеты «Видеотока»

Старые ассеты `assets/video` больше не используются.

## Обложки роликов

Путь:

```text
assets/videotok/thumbs/video-001.webp
...
assets/videotok/thumbs/video-072.webp
```

Рекомендуемый размер: **1280×720 px**, соотношение **16:9**.

## Аватары каналов

Путь:

```text
assets/videotok/channels/channel-001.webp
...
assets/videotok/channels/channel-012.webp
```

Рекомендуемый размер: **800×800 px**, соотношение **1:1**.

До загрузки настоящих файлов используются нейтральные заглушки Icons8. Имена файлов уже закреплены в `src/videotok.js`, поэтому для подключения обложек править код не потребуется.
