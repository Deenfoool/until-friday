# Состояние разработки

Актуально после централизации состояния, перехода инфраструктуры и вторника на lifecycle-события, исправления обязательств понедельника и добавления симуляций сохранения.

## Текущий статус

Игровой цикл от главного меню до концовки собран на все пять рабочих дней. Ветка `main` содержит интерактивные задачи, условные последствия, пятничную встречу и итоговый экран. GitHub Pages настроен на публикацию из `main`, однако развёртывание каждого последнего коммита вручную не подтверждалось.

## Автоматические проверки

В workflow подключены проверки движка, графа сюжета, сохранений, времени, интерфейса, ассетов, игровых дней и финала.

Новые регрессии:

- `tests/monday-requirement.test.js` — две из двух задач понедельника;
- `tests/event-driven-ui.test.js` — запрет системных наблюдателей и нейтральный профиль;
- `tests/full-playthroughs.test.js` — четыре полные недели;
- `tests/save-resume-days.test.js` — пересоздание движка после каждого рабочего дня и на пятничной встрече;
- `tests/scheduled-event-rollback.test.js` — откат времени отложенного события;
- `tests/notification-history.test.js` — подавление повторных писем через lifecycle-события.

Маршрутные симуляции покрывают:

1. честную работу и презентацию проекта;
2. расследование, досье и предъявление материалов;
3. вмешательство в журнал и жалобу на начальника;
4. добровольное заявление.

## Что не подтверждено

- Полный набор Node-тестов не запущен в текущей рабочей среде: DNS не разрешает `github.com`, поэтому свежую ветку нельзя клонировать локально.
- GitHub Actions не создаёт подтверждённые статусы для последних push в `main`.
- Последние изменения не проверены ручным прохождением в браузере.
- Не подтверждены все разрешения экрана и мобильное управление на реальных устройствах.
